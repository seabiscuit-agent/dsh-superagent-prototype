# GPT Image 2.6（产品名 Images 2.6）：形态与 DSH / Orca 可用性

调研日期 2026-11-18。TL;DR：它是**独立的图像生成模型家族**（不是 GPT 对话模型内嵌的能力），以三种面呈现；DSH 与 Orca 编排器**都没有开箱即用的生图**，但有 API 直调与 MCP/插件两条接入路径，另有 Codex 订阅通道（CLI 现状拿不到 2.6 新能力）。

## 它是什么（三种形态，本质是独立模型）
- 发布：2026-11-04（美东）/ 北京 11-05，全量可用（ChatGPT 全订阅档位 + Codex + API）。比上代快 50%，新增 GIF、markup 圈选编辑、SVG 导出。
- 1）**API 独立模型**：`gpt-image-2.6-flare`（快，low 质量最快 6 秒）与 `gpt-image-2.6-sunburst`（质量/多轮编辑一致性）。仅支持 `POST /v1/images/generations` 与 `/v1/images/edits`；模型页明列 Responses（作顶层模型）、Chat Completions 等一律 Not supported。
- 2）**工具形态**：Responses API 内置 `image_generation` 工具（顶层主模型如 gpt-6-astra，工具 `model` 字段指定 image 模型），支持多轮编辑与 File ID 输入；但 2.6 新能力（complexity/markup/SVG/GIF）官方指南明确写 "through the Image API"。
- 3）**产品集成**：ChatGPT（GIF 生成、保存参考图 @Pepper、圈选编辑）与 Codex 原生集成，用户不可自选 image 模型（由服务端 model_slug 决定）。
- 关键参数：`complexity` low/med/high（默认 high，无单独费用）、`quality` low→max、`markup`（edits 时同尺寸透明 PNG 圈选）、`output_format` png/jpeg/webp/**svg/gif**（GIF 配 `frame_count`+`frame_duration_ms`）。
- 门槛：GPT Image 模型要求 API Organization Verification；GIF 输出可能需要 preview access。
- 定价：text 输入 $5/1M（cached $1.25）、image 输入 $8/1M（cached $2）、image 输出 $30/1M；1024² 每张 low $0.025 → medium $0.043 → high $0.053 → xhigh $0.094 → max $0.211。

## DSH（DeepSeek Harness）：现在不能开箱即用，两条接入路径
- 实测证据：本会话工具面无生图工具；`dsh-base`、`dsh-web-app` 包 grep `imagegen|image_gen|generate_image|gpt-image` **零命中**；环境无 `OPENAI_API_KEY`。
- 路径 A（当天可用）：agent 会话内 bash+curl 直调 Images API。需 owner 提供已过 org verification 的 key；每张 $0.02–0.21，属付费动作，每次调用按 real-cost gate 单独确认。
- 路径 B（工程化）：DSH 是插件/profile 架构且官方示例含 MCP overlay，可挂一个封装 gpt-image 的 MCP server，使其成为会话一等工具。
- 借 Codex 订阅通道：官方把 2.6 放进了 Codex，但已发布 Codex CLI 的内置 `image_gen` 固定 `gpt-image-2`，ChatGPT/Codex OAuth 图片端点忽略 `model`/`complexity`/SVG、拒绝 GIF（openai/codex#59890，2026-11-06 实测）→ 走 CLI/第三方 OAuth 拿不到 2.6。

## Orca 这类编排工具：编排器本身无生图，取决于派的 worker
- Orca 能力面 = worktree、终端、自动化、内嵌浏览器、派工多 agent（Claude、Codex、Grok、OpenCode 等），无生图命令/工具；本机装有并在运行（/Applications/Orca.app 1.4.248 + daemon）。
- Codex worker：订阅通道可生图，但同上，CLI 实际是 `gpt-image-2` 行为，2.6 参数无效。
- 其它 worker（Claude 等）：同 DSH，需要 OPENAI_API_KEY + curl。
- 完整 2.6 体验在 ChatGPT 端（GIF/参考图/markup），可经 Orca 内嵌浏览器走 UI 生成，但那是产品操作，不是编排 API 集成。

## 坑
- 2.6 上线后 Responses API `image_generation` 工具回归 bug：`reasoning.effort` 被转发为 image 模型的 `complexity`，对 gpt-image-2/2.5 报 400 "Complexity 'X' is not supported"。
- SVG 仅 generations 端点、`n=1`、不支持流式；edits 端点不能输出 SVG。GIF 帧数上限文档说法不一（guide 2–64 vs API reference 2–16）。
- 第三方客户端借 ChatGPT/Codex OAuth：2.6 参数被静默忽略（返回 200 但实际是旧行为），易误判。

## 验证命令
- 包内零命中：`grep -r -o -iE "imagegen|image_gen|generate_image|gpt-image" <dsh-base|dsh-web-app> --include="*.js"`
- 官方指南原文：`curl -sL "https://developers.openai.com/api/docs/guides/image-generation.md?model=gpt-image-2.6"`
- 环境：`env | grep -i openai`（无输出）
